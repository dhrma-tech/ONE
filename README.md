# ONE

One place to lock in. A distraction-free, local-first PWA for career, mind, body and persona. No AI, no feeds, no infinite scroll, no notifications.

Status: under active build. See `docs/PROGRESS.md` and `docs/PLAN.md`.

## Quick start (Windows PowerShell or Git Bash)
```
pnpm install
pnpm dev            # http://localhost:5173 (local mode: no keys needed)
pnpm check          # typecheck + lint + tests + build
```
Full setup, env vars, deploy and install steps: see the sections added at the end of the build (Phase 17).
